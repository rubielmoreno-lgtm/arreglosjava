# Actividad de Operaciones con Vectores

## Objetivo

Desarrollar un programa en Java que permita practicar diferentes operaciones con vectores de números enteros, incluyendo el ingreso y validación de datos, búsqueda de valores, determinación del número mayor y menor, identificación de múltiplos, cálculo de la suma y creación de un nuevo vector con los valores que se encuentran por encima del promedio.

## Tecnologías utilizadas

* Java
* JDK Eclipse Temurin
* Visual Studio Code
* Git
* GitHub

## Descripción del proyecto

El programa crea un vector de 15 números enteros. El usuario debe ingresar valores entre 10 y 100. Si introduce un valor fuera de este rango, el programa muestra un mensaje de error y solicita nuevamente el número.

Una vez lleno el vector, el programa permite realizar las siguientes operaciones:

1. Mostrar los valores del vector.
2. Buscar un valor dentro del vector.
3. Mostrar la posición donde se encuentra el valor buscado.
4. Determinar el número mayor.
5. Determinar el número menor.
6. Identificar los múltiplos de un número X.
7. Calcular la suma de todos los valores.
8. Calcular el promedio.
9. Crear un nuevo vector con los valores superiores al promedio.
10. Indicar cuántos valores están por encima del promedio.
